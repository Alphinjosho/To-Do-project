# To-Do List App 📝

A simple and clean To-Do List application built with HTML, CSS, and JavaScript.

## 🚀 Features

- ✅ Add new tasks
- 📝 Edit existing tasks
- ❌ Delete tasks
- ✅ Form validation to prevent empty tasks
- 💾 Save tasks in Local Storage (auto-saves your data!)

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
